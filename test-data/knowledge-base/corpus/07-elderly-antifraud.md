# 老年人防诈骗提示手册（青川市社区版）

文件编号 QC-FZ-2027-06　发布机关：青川市反电信网络诈骗中心

> 本文为虚构测试资料，用于知识库检索评测。文中案例、号码均为虚构或公开常识。

## 一、常见骗局类型

### 1. 冒充公检法

对方自称公安、检察院、法院工作人员，声称你涉嫌洗钱或身份信息被盗用，
要求把钱转入"安全账户"配合调查。

**要点：真正的公检法不存在"安全账户"，也从不通过电话要求转账。**

### 2. 保健品与理疗仪

以免费体检、免费旅游、专家义诊为名，夸大产品功效，
诱导高价购买普通食品或器械。

**要点：保健食品不是药品，不能治病。包装上有蓝色"小蓝帽"标志的才是保健食品。**

### 3. 投资理财与养老项目

承诺高额回报、保本保息，以"养老公寓""以房养老""原始股"为名集资。

**要点：承诺年化收益超过 6% 就要打问号，超过 10% 要准备损失全部本金。**

### 4. 冒充亲友

通过盗号或改号软件冒充子女、孙辈，以出事、住院、交学费为由要钱。

**要点：挂断后用自己存的号码回拨核实，不要用对方提供的号码。**

## 二、转账前的三个自问

1. 对方是不是通过电话、短信、网络单方面联系我的？
2. 有没有人要求我"不要告诉家人"？
3. 钱是不是要转到我不认识的个人账户？

**三个问题里有任何一个答"是"，先停下来，打电话问家人或社区。**

## 三、求助渠道

- 全国反诈专线：**96110**（接到该号码来电务必接听，说明你可能正在被骗）
- 报警：110
- 社区网格员：由所在社区公示，和风苑社区在服务中心一楼公告栏张贴

## 四、被骗后怎么办

1. **立即拨打 110**，越快越有可能拦截资金。
2. 保留转账记录、聊天记录、通话记录。
3. 不要因为怕被家人责怪而隐瞒，隐瞒会错过止付时机。
4. 不要相信任何"追赃挽损""帮你追回被骗资金"的二次收费——那是二次诈骗。

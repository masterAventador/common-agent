# 项目设计资料

本目录保存 Common Agent 前端的设计基线与参考原型。

- `DESIGN.md`：新增和改造 UI 时必须遵守的设计规范原件。
- `PowerAI Atlas.html`：使用该规范制作的自包含交互原型，仅用于参考布局、组件、交互和动效代码。

## 项目适用边界

1. 设计规范负责视觉、排版、间距、组件状态、图标、动效和文案风格。
2. HTML 原型不负责定义本项目的产品范围、路由、权限、模型目录、接口或数据结构。
3. 可以复用原型的负荷曲线与蓝色火花节点动效 Logo，但不得使用 `PowerAI` 名称；正式界面使用
   本项目自己的产品名称和文案。
4. 原型中的电力行业内容、账号、供应商和演示数据只作为占位示例，不得进入正式业务数据或测试
   断言。
5. 正式实现必须继续使用 React、TypeScript、Vite 和 Ant Design，通过项目 API 读取真实数据，
   不能嵌入或跳转到本 HTML 代替功能实现。
